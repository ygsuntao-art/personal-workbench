# 知识库卡片大厅设计

知识库导航增加两层结构：点击侧栏“知识库”进入卡片大厅，点击卡片进入该知识库的目录与编辑页面。大厅包含置顶知识库、全部知识库、搜索、新建知识库和统一“新建”菜单，不加入成员、权限、统计或团队功能。

每个知识库使用一个根文件夹节点表示，并增加简介、封面、置顶状态和最近打开时间。现有根文件夹自动兼容为知识库卡片，文档数据不迁移、不丢失。知识库内部只展示该根节点的后代，顶部提供返回大厅、新建文档、新建文件夹；创建后直接进入或聚焦新节点。

第一版支持：新建知识库、名称、简介、预设渐变封面、搜索、置顶、重命名、删除、进入知识库、在当前知识库新建文档和文件夹。知识库删除沿用回收站机制。统一“新建”下拉提供知识库、文档、文件夹；在大厅新建文档或文件夹时先选择目标知识库。

验收包括：现有知识库生成卡片；新建知识库后立即出现并可进入；刷新后卡片与内容保留；知识库之间目录隔离；置顶顺序正确；搜索知识库名称和简介；代码检查、生产构建和真实浏览器操作通过。
