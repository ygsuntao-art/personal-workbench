# 文件库新建与右击菜单设计

## 范围

统一文件库列表、网格、左侧目录和空白区域的操作入口，并补充可编辑的内部文档、内部表格和 TXT 文件。知识库已有右击菜单继续沿用相同的关闭、越界和危险操作规则。

## 新建入口

- 顶部主按钮改为“新建”下拉菜单。
- 支持新建文件夹、文档、表格和 TXT。
- 上传文件仍保留为独立按钮。
- 新项目创建在当前目录；从文件夹右击菜单创建时进入该文件夹。
- 重名自动追加 `(1)`、`(2)`。

## 右击菜单

- 空白区域：新建文件夹、文档、表格、TXT、上传文件、刷新。
- 文件夹：打开、在此新建四类内容、上传到此、重命名、创建副本、移动到、查看详情、移到回收站。
- 文件：打开或预览、重命名、下载（有 Blob 时）、创建副本、移动到、查看详情、移到回收站。
- 左侧目录、列表行、网格卡片和三个点按钮共用同一个菜单组件。
- 点击空白、滚动或按 Esc 关闭；菜单坐标限制在视口内。
- 回收站继续使用恢复和永久删除菜单，不提供新建。

## 内部文件

- 文档复用知识库富文本编辑器。
- 表格复用知识库 Univer 表格编辑器。
- TXT 使用轻量纯文本编辑器。
- 内容继续存入 IndexedDB；刷新后可恢复。
- 本阶段属于工作台内部格式，不伪装为真实 DOCX/XLSX；后续再增加导出。

## 打开行为

- 双击或菜单“打开”进入大尺寸编辑浮层。
- 编辑浮层保留文件名、保存状态和返回文件库入口。
- 内部文档、表格、TXT 可编辑；上传的图片、PDF、视频沿用预览；其他上传文件提示下载打开。

## 一致性优化

- 三个点与右击菜单能力一致。
- 右击条目时同步选中该条目。
- 菜单不干扰内部拖动和桌面文件上传。
- 危险操作统一使用红色并保留回收站机制。
- 窄屏仍保留顶部新建菜单和条目三个点入口。

## 验收标准

1. 当前目录空白处右击可创建四类内容。
2. 左侧文件夹右击“在此新建”后，内容进入该文件夹。
3. 列表和网格右击菜单能力一致。
4. 文档、表格和 TXT 创建后可以打开编辑并刷新保留。
5. 同名项目自动编号而非覆盖。
6. 菜单在屏幕边缘不溢出，点击空白、滚动和 Esc 均可关闭。
7. 原有上传、拖动、预览、移动和回收站功能不回退。
