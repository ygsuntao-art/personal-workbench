# 任务归档、回收站批量管理与文件打开设计

## 已完成任务

- 旧完成任务进行一次性迁移：有效创建时间作为归档日期，无效演示时间使用迁移当天。
- 新任务使用真实 `completedAt`。
- 日期组支持折叠；今天和昨天默认展开，更早日期默认收起。
- 提供全部展开和全部收起。

## 文件库与知识库回收站

- 回收站入口右击提供打开、恢复全部、清空回收站。
- 回收站页面提供批量管理、全选、恢复所选、永久删除所选和清空。
- 永久删除与清空均显示数量并二次确认。
- 文件夹/目录的恢复和永久删除按整棵子树处理，避免孤立条目。

## Web端文件打开

- 内部文档、表格、TXT继续使用现有编辑器。
- 图片、PDF、视频沿用预览；新增音频播放。
- TXT、Markdown、JSON和常见代码文件以文本查看器打开。
- CSV以表格预览打开。
- ZIP显示压缩包内目录；读取失败时给出下载提示。
- Word、Excel、PPT和未知格式展示文件信息与下载入口，并说明桌面端后续支持WPS/系统应用。
