# 文件库全屏编辑与文件夹拖放修复

## 目标

- 双击文件库内部文档、表格或 TXT 后，默认全屏打开。
- 内部文档与表格继续复用知识库编辑器并自动保存。
- 列表视图和网格视图中的文件夹均可接收工作台内部文件拖放。
- 普通、专注、全屏按钮保持固定尺寸，不因文件名或窗口宽度被压扁。

## 交互

- 将表格、文档或其他文件拖到文件夹行/卡片上，松开后移动到该文件夹。
- 拖动经过文件夹时显示蓝色目标反馈。
- 打开文件时默认全屏，仍可切换到专注或普通模式。
- 原始 Word、Excel 上传文件保留原文件；本阶段不伪装成可无损在线编辑，工作台内部文档和表格支持正常编辑保存。

## 验证

- 列表、网格两种视图各验证一次拖入文件夹。
- 验证文档和表格打开后的默认模式为全屏。
- 验证模式按钮不换行、不压缩。
- 运行 lint、生产构建和页面错误检查。
