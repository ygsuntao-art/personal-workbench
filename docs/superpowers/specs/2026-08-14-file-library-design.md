# 文件库第一阶段设计

## 目标与边界

在现有个人工作台中交付可点击、可验证的文件库原型，用于确认目录、文件浏览、管理和预览交互。第一阶段仅处理小型测试文件，不扫描真实 `D:\个人工作台\`，不导入大容量文件，不接 Tauri、云存储、后端或权限系统，也不实现 Office 在线编辑和 ZIP 在线解压。

## 第一阶段功能

- 任意层级文件夹树，支持展开、收起、新建、重命名、移动、排序和删除。
- 小型测试文件的多选上传、下载、重命名、移动、删除和应用内回收站。
- 列表视图与网格视图。
- 按名称、修改时间、大小和类型排序，以及文件名搜索。
- 图片预览、PDF 预览和视频播放。
- Word、Excel、PPT、ZIP 和普通文件显示文件信息并支持下载。
- 使用 IndexedDB 保存目录、文件元数据及测试文件内容。
- 所有条目第一阶段均显示“仅本地”，不显示可操作的云同步入口。

## 页面结构

文件库沿用固定主导航。右侧顶部工具栏包含标题、文件数量、搜索、上传、新建文件夹、列表/网格切换和排序。下方工作区左侧为约 240 至 280 像素宽的目录树，右侧为面包屑和文件区域。

目录节点包含展开按钮、文件夹图标、名称和操作菜单。目录拖拽使用 dnd-kit：拖到另一文件夹表示移动，同级拖动表示排序，禁止移动到自身或自己的后代。

列表视图展示名称、大小、类型、修改时间、存储状态和操作菜单。网格视图使用统一卡片；图片显示缩略图，视频显示播放标记，其他文件显示类型图标。

## 核心交互

新建文件夹在当前目录顶部使用行内命名框，Enter 创建、Esc 取消；重复名称显示行内错误。

上传允许一次选择多个小型测试文件。原型设定明确的单文件大小限制，超限时说明测试模式限制，不读取文件。文件写入 IndexedDB，并记录名称、类型、大小、修改时间和父目录。

重命名使用当前位置行内编辑。文件可以拖入目录树目标，也可以通过“移动到”菜单选择目录；移动只更新父目录关系，不复制文件内容。

删除会把条目标记为已删除并放入应用内回收站。回收站支持恢复和永久删除，只有永久删除需要二次确认。

图片、PDF 和视频在页面内预览；不支持预览或预览失败时显示文件信息与下载入口，不能导致页面崩溃。

## 数据与组件边界

统一条目模型包含 `id`、`parentId`、`kind`、`name`、`mimeType`、`size`、`modifiedAt`、`storageState`、`sortOrder`、`deletedAt` 和文件专用 `blob`。目录树、面包屑、文件区和搜索共用同一数据源。

主要组件：

- `FileLibraryPage`：页面状态与布局。
- `FileLibraryToolbar`：搜索、新建、上传、视图和排序。
- `FolderTree`：层级、选择和拖拽。
- `Breadcrumbs`：当前路径。
- `FileList` / `FileGrid`：两种文件视图。
- `FileItemMenu`：重命名、移动、下载和删除。
- `FilePreview`：图片、PDF、视频和通用信息。
- `RecycleBin`：恢复与永久删除。
- `useFileLibrary`：查询、变更和派生数据。
- `fileLibraryStore`：IndexedDB 读写和版本迁移。

UI 不直接访问 IndexedDB，而通过数据适配器读写，便于第二阶段替换成 Tauri 文件系统适配器。

## 错误处理

IndexedDB 初始化时显示轻量加载状态；浏览器不支持时显示明确错误，不回退为易丢失数据的内存模式。上传超限、读取失败、名称冲突和预览失败均在操作位置反馈。永久删除需要确认，其他删除先进入回收站。

## 开源复用

- 目录和文件拖拽复用现有 dnd-kit。
- PDF 预览使用 PDF.js 或 React PDF。
- 视频使用浏览器原生播放器。
- 云端分片上传阶段再评估 Uppy。
- 不整体引入 Chonky，以保留当前设计语言和 Tauri 适配自由度。

## 验证标准

- 创建至少三级目录并显示正确面包屑。
- 上传多个小型测试文件，刷新后仍存在。
- 列表与网格展示相同数据。
- 搜索、排序、重命名和移动结果正确。
- 目录拖拽不能产生循环层级。
- 删除后进入回收站，恢复后回到原位置。
- 使用真实图片、PDF、视频分别完成预览验证。
- 不支持预览的文件可以下载。
- 构建、类型检查和代码检查通过。
- 使用真实浏览器完成端到端交互并检查控制台错误。

## 第二阶段

页面交互确认后，以 Tauri 文件系统适配器替换 IndexedDB 适配器，支持选择真实目录、扫描元数据、监听变化和执行原生文件操作。真实文件不默认复制到应用目录，也不默认上传云端。
